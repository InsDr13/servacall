# Serva Call

Crée une première version simpliste de mon application serva call, c'est une application web permettant au utilisateur de passer des voice call, L'idée est de permettre à l'utilisateur connecté à internet de passer un appel à une personne non connecté via GSM. Prépare moi juste la partie front end, les formulaires de créeation de compte, de validation de numéro de téléphone OTP,  de faire un appel ,  L'application doit permettre le voice call et voice message, voice message soit enregistrer un audio ou écrire du texte. Avoir historique des appels, journals, les répertoires des numéros, le solde , acheter des soldes,  les notifications, les messages de confirmation, et autres. La sélection automatique d'un pays après que l'utilisateur entre le code numéro pays.  Et d'autres options de paramètre pour appel en rapport avec infobip, parce que plus tard nous allons joindre infobip qui va s'occuper de passer les appels. Fais d'abord le front end avec tous les menus, et autres options en rapport avec ceux proposé par infobip voice api.
